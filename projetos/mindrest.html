MindRest

Plataforma web com conteúdos e exercícios para lidar com a ansiedade no dia a dia.

Ver código no GitHub

Sobre o projeto

O MindRest oferece uma abordagem prática para lidar com a ansiedade. A página inicial traz curiosidades e dicas sobre o tema, e o site tem duas ferramentas: um exercício de respiração guiada e uma seleção de músicas relaxantes.

Minha participação

Participei de todo o desenvolvimento em equipe: layout e estilização das páginas, navegação, carrossel da página inicial e a lógica em JavaScript do exercício de respiração.
