Estocaí

Sistema web de controle de estoque com dashboard de vendas e gestão de funcionários.

Ver código no GitHub

Sobre o projeto

O Estocaí é um sistema de gestão de estoque para pequenos comércios. A loja se cadastra, adiciona produtos com categoria, validade e imagem, e acompanha entradas, vendas e lucro.

O dashboard reúne gráficos de produtos mais vendidos, vendas por dia, comparação de estoque e histórico de entradas. O administrador também cadastra funcionários com permissões diferentes.

Minha participação

Participei de todo o desenvolvimento: telas de login e cadastro, cadastro e edição de produtos, controle de estoque, dashboard com gráficos em Chart.js e integração com Firebase Authentication e Firestore. É o projeto que mais conversa com a minha área de dados, porque transforma o estoque em indicadores para a tomada de decisão.
