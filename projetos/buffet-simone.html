Site do Buffet Simone

Site institucional para um buffet de eventos, com cardápio dinâmico e área administrativa.

Ver código no GitHub

Sobre o projeto

Site criado para o Buffet Simone, empresa de eventos com mais de 15 anos de mercado. A página apresenta a história da chef, o cardápio, depoimentos e um canal de contato para pedidos de orçamento.

O cardápio e as fotos são gerenciados por uma área administrativa com login, onde é possível criar categorias, cadastrar pratos e enviar imagens, tudo salvo no Firebase.

Minha participação

Participei de todo o desenvolvimento do projeto em equipe: estrutura das seções da página inicial (hero, sobre, cardápio, contato), componentes de interface em React com TypeScript e a área administrativa integrada ao Firebase para o cadastro de pratos, categorias e fotos.
